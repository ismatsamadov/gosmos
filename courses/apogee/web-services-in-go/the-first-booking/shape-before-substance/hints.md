A `switch` with nothing after the word `switch` runs the first `case` that is true, which keeps the rules in order: one `case` per rule, each returning `invalidBooking` with its message.

A time that was never set is the zero time, which its `IsZero` method reports. `After` says whether one time is later than another, so an `los` equal to `aos` is not after it.

If the 200-character note with `Ñ` in it is refused, the note is measured with `len`, in bytes: count its characters with `utf8.RuneCountInString` instead.

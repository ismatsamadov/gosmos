Keep, for each file, the passes bringing it down now: a pass joins when the file's FILE comes on its call or its DUMP_FILE is answered with an ACK, and leaves at the file's END or at its own LOS. A file that hasn't landed and that no pass is bringing down is one to ask for.

Work out the DUMP_FILEs with the rest of a pass's commands, when it takes the satellite's lock: one per incomplete file of that satellite, the name and the missing numbers ascending, or the name alone after a CRC mismatch. It is signed or sealed like a PING, and the chunks it asks for come down on the pass that sent it: one an earlier contact left unanswered at LOS sent them there, if anywhere.

A DUMP_FILE sent while another station was still bringing the file down means that pass's hold was missing; one after 08:12:30 for Furrow-K means a landed file wasn't left out. An event for a file that lands on a later contact still names its booking's station.

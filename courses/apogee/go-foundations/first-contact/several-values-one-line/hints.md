How many lines should the output have? That is how many `fmt.Println` calls `main` needs.

Give one `fmt.Println` all the values for its line, separated by commas, in the order they appear. It adds the spaces between them itself.

Skeleton for the battery line: `fmt.Println(___, ___, ___, ___)`, with the text in quotes and `7.91` as a number, without them.

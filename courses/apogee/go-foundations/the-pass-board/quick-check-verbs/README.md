You are about to put your fixes into use on the Board, and nobody changes it without passing Ingrid's check. She points at three lines of its code and asks what each one prints. The brackets are part of each format string, so they show exactly where the padding goes:

```go
fmt.Printf("[%5.1f]\n", 7.91)
fmt.Printf("[%-4s]\n", "YST")
fmt.Printf("[%03d]\n", 7)
```

Work out each line in your head first, then pick the answer that matches it.

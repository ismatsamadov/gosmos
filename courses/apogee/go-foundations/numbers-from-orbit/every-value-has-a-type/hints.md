Sort the three values first: which one is a whole number, which has a fraction, and which is `true` or `false`? Each answer names a type.

The types are `int`, `float64` and `bool`. A declaration reads `var`, the name, the type, `=` and the value, like the line for `name`.

Skeleton: `var beaconMHz ___ = ___`, and below the existing print, one more per variable, such as `fmt.Println("Beacon MHz:", ___)`.

Monday afternoon. Before Go's own client meets the station server, Nkem sends three questions from Port Ellery about an answer such as this one, as it crosses the line:

```text
HTTP/1.1 201 Created\r\n
Content-Length: 37\r\n
\r\n
stored furrow-a/YST/18856 4096 bytes\n
```

## Your task

Answer Nkem's three questions: which part of a status line a client acts on, where the head ends, and what a client can do with an answer that gives no length.

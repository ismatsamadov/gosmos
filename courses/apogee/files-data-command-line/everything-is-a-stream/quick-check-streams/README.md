The recorder can now accept a file or an in-memory source and write to a chosen destination. Nkem checks the boundaries before Paz adds a second destination.

A stream interface describes the direction bytes move, rather than where they are stored. The copy helper combines a reader with a writer.

## Your task

Answer three questions about readers, writers and copying. The last one asks what the copy helper must report when a copy stops partway through.

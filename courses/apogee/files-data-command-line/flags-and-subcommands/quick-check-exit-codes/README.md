Ingrid won't put gctl in the night shift's checklist until every status it returns has one meaning. She runs three commands from the Fishbowl and asks what `run` returns for each.

A script acts on the status alone, so each one must keep its meaning: the command did what was asked, the command line was wrong before any work began, or the work was tried and failed.

## Your task

Choose the status `run` returns for a request for help, a misspelled flag and a file that isn't there.

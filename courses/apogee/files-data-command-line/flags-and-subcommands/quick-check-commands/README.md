Nkem reads gctl's first functions from Port Ellery while the van has a signal, and sends her review the way she always does: one question at a time.

Standard output carries what a command produces, and the help someone asked for. Standard error carries what went wrong: mistakes and failures. The exit status tells whatever started gctl how it went, and `run` returns it rather than ending the process itself.

## Your task

Answer three questions about where gctl's lines go and how `run` hands back its status.

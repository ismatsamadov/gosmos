Ingrid checks the calibration-day clock before anyone plans around it: every AOS and LOS in UTC, the van's clock beside them, and how long each pass lasts. "Three questions. Answers before the next stop."

A time is one instant, an offset is how that instant is written, and a duration is the length between two instants. Keep the three apart and the plan agrees with every clock.

## Your task

Answer three questions: what `Sub` measures, what `In` changes, and what a duration carries.

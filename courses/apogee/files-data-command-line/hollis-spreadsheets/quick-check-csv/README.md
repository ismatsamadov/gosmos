The van finds a signal at 2,800 m, and Nkem reviews the spreadsheet reader from Port Ellery, one question at a time. She starts from these lines of a sheet Hollis sent:

```
ID,STATION,NOTE
bk-2117,SQT,"PRIORITY, CALL HOLLIS"
bk-2118,SQT,"SAYS ""URGENT""
TWICE"
```

## Your task

Answer Nkem's three questions: how the lines split, how many records a CSV reader finds in them, and what a header that repeats a name means for the reader.

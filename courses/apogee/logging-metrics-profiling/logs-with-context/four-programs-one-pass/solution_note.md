`stamp` gives every record the replay's time, `passHandler` adds the pass and request IDs from each call's context after the record's own attributes, and `With` puts the program and its site before them, so each of the four programs writes lines the one search can follow. Because `passHandler` returns itself from `WithAttrs`, the logger `With` makes still adds the IDs, and Lantern Atoll's failure line comes out exactly as the night shift reads it.

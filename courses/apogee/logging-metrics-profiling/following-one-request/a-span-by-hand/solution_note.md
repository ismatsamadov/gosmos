A child copies its parent's trace ID and names the parent's span ID, so every span of a pass shares one trace and points at the step it belongs to; only a root draws a trace ID, always before its span ID, which keeps the IDs the same on every run from one seed. Holding `t.mu` around the draws keeps two goroutines from using `Rand` at once, and the context `withSpan` returns carries the new span to the steps inside it.
